================================================================================
     SISTEMA DINAMICO DE FASTFETCH — INSTRUCCIONES DE USO
================================================================================

Este directorio (mis-presets) contiene un sistema autocontenido para hacer tu
fastfetch dinamico en Caelestia/Hyprland.

Es compatible tanto con terminales Kitty como Foot, mezclando logos PNG y arte
ASCII (.txt). Ahora soporta MULTIPLES PRESETS (configs .jsonc) que puedes
alternar con un solo comando.

================================================================================
                          CLONAR DESDE GITHUB
================================================================================

Todas las configuraciones estan en: https://github.com/frameix/mis-config

Clonar solo Caelestia:

    git clone --no-checkout https://github.com/frameix/mis-config.git
    cd mis-config
    git sparse-checkout init --cone
    git sparse-checkout set Caelestia
    git checkout main

Clonar solo Fastfetch:

    git clone --no-checkout https://github.com/frameix/mis-config.git
    cd mis-config
    git sparse-checkout init --cone
    git sparse-checkout set Caelestia/Fastfetch
    git checkout main

Una vez clonado, copia mis-presets:

    cp -r mis-config/Caelestia/Fastfetch/mis-presets ~/.local/share/caelestia/fastfetch/

================================================================================
                       PREGUNTAS FRECUENTES (FAQ)
================================================================================

QUE ARCHIVOS HAY Y QUE HACE CADA UNO:

  preset-f1.jsonc          Preset original de Fastfetch. Define que info se
                           muestra (OS, CPU, GPU, RAM, etc.) y el diseno visual.

  caelestia-modify.jsonc   Preset con diseno de recuadro con bordes Unicode.
                           Muestra info compacta con iconos Nerd Font.

  alterfetch.sh            Lanzador multi-preset. Randomiza el logo y ejecuta
                           fastfetch. Acepta: nombre, -pN, --list, -h.

  randomize.sh             Motor de rotacion. Elige un logo y crea el symlink
                           current. No muestra nada, solo prepara el logo.

  set_mode.sh              Cambia entre modo aleatorio o fijo para logos.
                           Guarda en mode.txt. Usa -h para ayuda.

  set_preset.sh            Cambia entre presets (.jsonc). Guarda en preset.txt.
                           Usa -h para ayuda.

  greeting_example.fish    Plantilla para integrar con Fish shell.

CARPETA presets/:

  presets/*.jsonc           Los presets. Puede haber tantos como quieras.
  presets/logos/            Logos: PNG/JPG e imagenes ASCII (.txt).
  presets/current           Symlink al logo activo (NO tocar manualmente).
  presets/mode.txt          Modo de logos: random o archivo fijo.
  presets/preset.txt        Preset activo (ej: preset-f1).

COMO SE RELACIONAN:

  Terminal se abre
      |
      v
  fish_greeting.fish --> randomize.sh --> Elige logo --> Crea symlink "current"
      |                                                        |
      v                                                        |
  Lee preset.txt --> fastfetch --config <preset>.jsonc <--------+
      |                     (el .jsonc lee "current")
      v
  Muestra tu sistema con el logo + preset elegidos

PREGUNTAS RAPIDAS:

  Puedo usar esto sin Fish? Si. Ejecuta ./alterfetch.sh desde Bash/Zsh.
  Que pasa si borro current/mode.txt/preset.txt? Se recrean solos.
  Necesito instalar algo extra? Solo fastfetch.
  Funciona en Kitty y Foot? Si.

================================================================================
                        1. UBICACION CORRECTA
================================================================================

    mkdir -p ~/.local/share/caelestia/fastfetch/
    cp -r mis-presets ~/.local/share/caelestia/fastfetch/

================================================================================
                     2. PRUEBA RAPIDA (Sin instalar nada)
================================================================================

    cd ~/.local/share/caelestia/fastfetch/mis-presets/
    ./alterfetch.sh               # Logo random + ultimo preset
    ./alterfetch.sh -p1           # Primer preset
    ./alterfetch.sh -p2           # Segundo preset
    ./alterfetch.sh --list        # Ver todos los presets

================================================================================
               3. INTEGRACION CON TU TERMINAL (El Greeting)
================================================================================

Editar: ~/.config/fish/functions/fish_greeting.fish

    function fish_greeting
        cd ~/.local/share/caelestia/fastfetch/mis-presets/
        bash randomize.sh
        set -l preset "preset-f1"
        if test -f presets/preset.txt
            set preset (string trim (cat presets/preset.txt))
        end
        fastfetch --config "presets/$preset.jsonc"
        cd ~
    end

================================================================================
                   4. COMANDOS MANUALES GLOBALES
================================================================================

Crear funcion para alterfetch:

    echo 'function alterfetch; bash ~/.local/share/caelestia/fastfetch/mis-presets/alterfetch.sh $argv; end' > ~/.config/fish/functions/alterfetch.fish

USO DE ALTERFETCH:

    alterfetch                     Logo random + ultimo preset usado
    alterfetch -p1                 Logo random + primer preset (atajo)
    alterfetch -p2                 Logo random + segundo preset
    alterfetch caelestia-modify    Logo random + preset por nombre
    alterfetch --list              Lista presets con su numero -pN
    alterfetch -h                  Muestra la ayuda

MODOS DE LOGOS (dentro de mis-presets/):

    ./set_mode.sh random           Rota automaticamente (por defecto)
    ./set_mode.sh 1.png            Fija un logo permanente
    ./set_mode.sh -h               Ayuda

CAMBIAR DE PRESET (dentro de mis-presets/):

    ./set_preset.sh                Muestra preset actual + lista
    ./set_preset.sh -p1            Fija el primer preset
    ./set_preset.sh caelestia-modify   Fija por nombre
    ./set_preset.sh -h             Ayuda

================================================================================
                      5. COMO AGREGAR MAS LOGOS
================================================================================

Arroja tus PNG, JPG o .txt con arte ASCII dentro de:

    mis-presets/presets/logos/

El script los reconocera automaticamente.

================================================================================
                  6. COMO CREAR TUS PROPIOS PRESETS
================================================================================

REGLA DE ORO: "source": "presets/current"

Toda config .jsonc que agregues DEBE tener esta linea en su seccion de logo:

    "logo": {
        "source": "presets/current",
        "type": "auto",
        ...
    }

PASO A PASO:

1. Consigue tu config .jsonc (descargada, copiada, o creada desde cero).

2. Modifica SOLO la seccion "logo": cambia "source" a "presets/current":

   ANTES (ruta fija):
       "source": "/ruta/a/mi/imagen.png"

   DESPUES (compatible con el sistema):
       "source": "presets/current"

3. No toques nada mas. Los modulos, colores, bordes... dejalo tal cual.

4. Copia el archivo a presets/:
       cp mi-config.jsonc ~/.local/share/caelestia/fastfetch/mis-presets/presets/

5. Listo! Ya puedes usarla:
       alterfetch mi-config
       alterfetch --list      # ver el numero asignado
       alterfetch -p3         # si es el tercero

ERRORES COMUNES:

  - Poner ruta absoluta en source    --> Usar "presets/current"
  - Borrar la seccion logo           --> Mantener con source: presets/current
  - Poner "logo": null               --> Cambiar a bloque logo completo
  - Sin extension .jsonc             --> Siempre usar .jsonc

TIPS DE DISENO:

  - Si usas bordes (|), usa {valor>22} para alinear a ancho fijo.
  - Ajusta width (18-27) y height (10-14) para que el logo no se solape.
  - Prueba siempre con: alterfetch nombre-de-tu-config
